================================================================================
DIGITAL AZADI SUPPORT — HOSTINGER DEPLOYMENT GUIDE (आसान हिंदी गाइड)
================================================================================

यह ज़िप फ़ाइल (support-hostinger.zip) होस्टिंगर (Hostinger) पर डिप्लॉय करने के लिए 
पूरी तरह तैयार (Ready-to-Deploy) है। इसमें क्लाउड सिंक (.htaccess और API इंजन) 
पहले से कॉन्फ़िगर है।

--------------------------------------------------------------------------------
तरीका 1: होस्टिंगर वेब होस्टिंग (hPanel File Manager) — सबसे आसान (5 मिनट)
--------------------------------------------------------------------------------
यदि आपके पास Hostinger Premium / Business Web Hosting है:

1. अपने Hostinger अकाउंट में लॉगिन करें: https://hpanel.hostinger.com
2. "Websites" पर जाएँ और अपनी डोमेन (जैसे support.digitalazadi.com या digitalazadi.com) चुनें।
3. "File Manager" (फ़ाइल मैनेजर) पर क्लिक करें।
4. "public_html" फ़ोल्डर खोलें।
   (नोट: अगर आप sub-directory में डाल रहे हैं, जैसे digitalazadi.com/support, तो 
    public_html के अंदर "support" नाम का नया फ़ोल्डर बनाएँ और उसे खोलें)।
5. ऊपर दाईं ओर दिए गए "Upload" (अपलोड) आइकॉन पर क्लिक करें और "support-hostinger.zip" को अपलोड करें।
6. अपलोड पूरा होने के बाद ज़िप फ़ाइल पर राइट क्लिक (Right Click) करके "Extract" (एक्सट्रैक्ट) चुनें।
7. एक्सट्रैक्ट होने के बाद यह फ़ाइलें public_html में होनी चाहिए:
   - index.html
   - .htaccess (यह बहुत ज़रूरी है — राउटिंग और 404 फिक्स के लिए)
   - assets/ (CSS और JS फ़ोल्डर)
   - server.js (वैकल्पिक)
8. अब अपने डोमेन पर जाएँ:
   - पब्लिक क्वेरी पोर्टल: https://yourdomain.com/submit
   - एडमिन कमांड डेक: https://yourdomain.com/admin
   - ओंकार सर मेटा डेस्क: https://yourdomain.com/onkar

* क्लाउड सिंक: मोबाइल और लैपटॉप का रियल-टाइम क्लाउड सिंक होस्टिंगर पर भी 100% 
  ऑटोमैटिक काम करेगा! किसी भी अतिरिक्त सर्वर सेटअप की ज़रूरत नहीं है।

--------------------------------------------------------------------------------
तरीका 2: होस्टिंगर Node.js ऐप्लिकेशन (VPS / Cloud Hosting)
--------------------------------------------------------------------------------
यदि आप Hostinger VPS या Cloud Server पर Node.js से चलाना चाहते हैं:

1. फ़ाइलों को सर्वर डायरेक्टरी में अनज़िप करें।
2. टर्मिनल में रन करें:
     npm install --production
3. सर्वर स्टार्ट करें:
     node server.js
   (या PM2 से परमानेंट चलाएँ: pm2 start server.js --name "da-support")
4. सर्वर पोर्ट 3000 पर लाइव हो जाएगा।
